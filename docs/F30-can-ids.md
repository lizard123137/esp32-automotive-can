# F30 CAN IDs

Automotive CAN buses are described by `.dbc` files. Each ID and its payload is described within.

The IDs used by the f30 gauge cluster are:
- `0x0D7` - Alive count???
- `0x0F3` - RPM
- `0x12F` - Ignition
- `0x19B` - Airbag OK
- `0x1A1` - Speed
- `0x1F6` - Blinkers
- `0x202` - Display Brightness
- `0x21A` - Lights
- `0x289` - Cruise control
- `0x297` - Seatbelt OK
- `0x2A7` - Power steering OK
- `0x2C4` - Engine Temp
- `0x33B` - Acc
- `0x349` - Fuel
- `0x369` - TPMS OK
- `0x36E` - ABS OK
- `0x36F` - Parking Brake
- `0x3A7` - Drive Mode
- `0x3F9` - Oil Status
- `0x3FD` - Gear
- `0x5C0` - Alerts
